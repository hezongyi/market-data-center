# WebUI 可用性与访问治理 v0.5 规划

日期：2026-09-13
状态：draft
基线版本：v0.4.1
相关文档：`docs/specs/2026-09-11-webui-modernization.md`、`docs/specs/2026-09-13-webui-data-workbench-v0.4.md`

## 背景

v0.4.1 已提供 Overview、Data Catalog、Runs、Quality、Explorer、Maintenance 和 Operations 工作区。生产使用中发现界面仍以英文、UTC 单时区和临时 API Key 访问为主；长 ID、容量状态、时间信息、详情抽屉和维护任务可见性不足，影响单用户日常运维。

## 目标

1. 默认以简体中文提供核心操作界面并保留英文切换；深层诊断、审计和错误说明的完整本地化列入后续 spec。
2. 在不改变后端 UTC canonical 语义的前提下，让用户能同时理解 UTC 与 UTC+8。
3. 统一提升所有详情抽屉的可读性和响应式行为。
4. 让维护任务的运行、暂停、失败和手动生命周期状态可见。
5. 为单用户提供安全、低摩擦的登录和密码管理，同时保留 API Key 自动化入口。

## 非目标

- 不修改生产 canonical 数据、ledger、manifest 或当前 v0.4.1 deployment。
- 不在本迭代引入 RBAC、多租户、OIDC 或通用后台权限平台；认证使用单用户 SQLite session store，不引入完整身份平台。
- 不改变 API 返回时间的 UTC 格式和既有容量保护规则。

## 功能范围

### 语言、时间与状态表达

- 默认 locale 为 `zh-CN`，支持 `English`，偏好持久化在浏览器。
- v0.5 中文范围包括导航、工作区标题、主要表单标签、核心状态、主要按钮和关键 ID/时间字段；深层详情、诊断信息、审计字段和 provider 专有说明可以暂保英文。
- 后端时间继续以带时区 UTC 传输；前端统一使用 `TimeDisplay`。
- 默认显示 UTC+8，并提供 UTC 对照；设置可切换“本地+UTC / 仅本地 / 仅 UTC”。
- 主界面显示当前时间、时区和数据快照时间，三者文案明确区分。
- 容量徽章必须包含“容量/Capacity”、状态和 free ratio，例如“容量 · 正常 · 可用 11.7%”。
- Run ID、task ID、finding ID 等使用清晰等宽字体，支持复制和完整值查看。

### 统一详情抽屉

继续使用共享 `DetailDrawer`，升级为所有页面共用的详情容器。桌面宽度为 `min(680px, 52vw)`，复杂详情可到 760px；移动端接近全屏。抽屉应支持 ESC、遮罩关闭、焦点管理、内部滚动、固定标题栏和复制操作。

详情内容按基本信息、状态与时间、输入/输出、质量/错误、审计与操作分组；长 JSON 和错误堆栈可折叠。短确认、登录和编辑流程继续使用 Modal；复杂详情提供“打开完整详情页”。

### Maintenance 任务中心

增加任务列表视图，展示 task/run id、dataset、任务类型、当前状态、最近运行、最近错误和启用/暂停操作。支持按状态、数据集和类型筛选，并在 Overview 显示运行中、暂停和失败数量。v0.5 只承诺任务注册、手动提交、状态可见性和安全暂停/恢复；不承诺 hourly/daily 自动触发、到期扫描或服务重启后的计划恢复。

短期聚合现有 maintenance runs，保持既有 `/api/v1` envelope 和容量保护。自动调度由独立 spec 设计和验证后再实施；v0.5 不展示会造成自动执行暗示的 `next_run_at`，或将其明确标为计划字段。

### 单用户登录

增加初始化、登录、登出、改密和会话过期流程。密码使用 Argon2 哈希，认证使用 HttpOnly、SameSite Session Cookie，服务端使用 SQLite 持久化用户和 session。首次登录必须设置新密码；API Key 继续支持脚本和高级入口。禁止将长期有效的 `admin/admin` 作为默认生产凭据。

## 分阶段交付

1. **P0 UI 基础**：i18n、TimeDisplay、当前时间、容量徽章、ID 字体和复制。
2. **P1 详情与任务**：统一宽抽屉、详情分组、任务列表和状态聚合。
3. **P2 访问治理**：登录、改密、会话、未授权跳转和 API Key 兼容。

每阶段独立 PR，遵守受保护 `main`、必需 `verify` 和生产不变更要求。

## 验收标准

- 首次打开默认显示中文核心界面，语言切换刷新后保持；深层文案本地化不作为 v0.5 合并阻断项。
- 任一页面的时间均可看到 UTC+8 与 UTC，跨日转换正确。
- 当前时间每秒更新，快照时间不会被误标为当前时间。
- 所有容量状态均能看出“容量”含义并显示比例。
- 1440px、1024px、390px 下所有详情抽屉可读，长 ID 不发虚且可复制。
- Maintenance 列表能区分 queued、running、paused、succeeded、failed，并能安全暂停/恢复；v0.5 不要求 hourly/daily 自动 enqueue。
- 未登录写操作被拒绝并引导登录；改密后旧密码失效；API Key 调用契约保持兼容。
- Python 3.10/3.11/3.12、Node 22、`bash scripts/ci.sh all` 和隔离浏览器验收通过。
