# v0.5.0 — WebUI usability and access

This release delivers the WebUI v0.5 usability and single-user access scope.

## Changes

- Default Chinese interface with English toggle and persisted locale preference.
- Global UTC+8, UTC, and dual time presentation, including current-time display.
- Capacity context in the header and wider, responsive detail drawers.
- Copyable identifiers across runs, quality, snapshots, and maintenance views.
- Maintenance task registry with filtering, manual submission, status visibility,
  and safe pause/resume controls. Automatic hourly/daily scheduling is deferred
  to the dedicated maintenance scheduler spec.
- Single-user initialization, login/logout, password change, SQLite-backed
  Argon2 password storage, durable sessions, and API-key compatibility.

## Verification

The protected-main post-merge checks must pass Python 3.10/3.11/3.12, Node 22
browser acceptance, and aggregate `verify`. Release staging and production
activation must follow the immutable deployment checklist with isolated smoke,
backup/recovery, readiness, rollback, and retained receipts.
