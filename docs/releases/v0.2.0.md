# v0.2.0 — release and operational sustainability

Additive operational release; API and dataset query contracts remain compatible.

- Runtime: hosted Python 3.10/3.11/3.12 matrix and Node 22 browser build.
- Dependencies: committed full transitive locks selected by Python minor; scheduled refresh runs the full matrix, service acceptance, and browser acceptance.
- Web UI: Playwright 1.63.0 clean-runner acceptance covers readiness, datasets, filters, retry immutability, authorization, bars coverage, and mobile layout.
- Capacity: shared warning/critical policy across readiness, metrics, monitor, worker, retention audit, ingest, and backfill.
- Backup: `market-data-center-backup.v2` atomic no-replace publication, source identity, file size/hash manifest, streaming restore, v1 compatibility, and distinct-device production gate.
- Evidence: `operational-receipt.v1` for CI, dependency refresh, browser, capacity, backup, verify, restore, and recovery drill.

Compatibility: `/api/v1`, `provider_bars.v1`, `economic_observations.v1/v2`, existing manifests, and terminal run receipts remain readable. Backup v2 is the write default; v1 restore remains supported.

Rollback: check out `v0.1.0`, install `backend/constraints/py<minor>.txt` from that tag when available or its recorded dependency baseline, retain canonical history, restart API/worker, and run smoke/query parity. A rollback never moves either release tag.
